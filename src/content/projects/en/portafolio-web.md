## What is Personal Portfolio?

Personal Portfolio is a website created to showcase projects, technical skills, professional experience, and contact information in one modern and attractive platform.

## 🎯 Project Goal

To build a strong personal brand online through a visually impactful, fast, and optimized portfolio for recruiters, clients, and job opportunities.

## 🚀 Main Features

- Modern responsive design.
- Featured projects section.
- Dark / light mode.
- Multi-language support.
- SEO optimization.
- Smooth animations and professional interface.
